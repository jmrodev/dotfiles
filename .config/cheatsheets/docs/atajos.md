# ⚡ SWAY / NAVEGACIÓN & VENTANAS
- `Super + d`: Lanzador de aplicaciones
- `Super + e`: Explorador de archivos (Dolphin)
- `Super + Enter`: Terminal (Kitty + Herdr)
- `Super + i`: Workspace dedicado Chrome
- `Super + 1..9`: Cambiar a Workspace 1..9
- `Super + Tab`: Alternar con el workspace anterior
- `Super + f`: Pantalla completa (Fullscreen)
- `Super + Sh + Espacio`: Alternar ventana Flotante / Mosaico
- `Super + v`: Historial de portapapeles (cliphist)
- `Super + Shift + Q`: Cerrar ventana activa

---

# ⌨️ TMUX (Prefix: Ctrl+a)
- `C-a + v` / `s`: Dividir panel (vertical / horizontal)
- `C-a + h/j/k/l`: Moverse entre paneles (o Ctrl+hjkl)
- `C-a + H/J/K/L`: Redimensionar tamaño de panel
- `C-a + z`: Zoom / Maximizar panel actual
- `C-a + c` / `x`: Crear nueva ventana / Cerrar panel
- `C-a + f`: Sessionizer (selector fzf de proyectos)
