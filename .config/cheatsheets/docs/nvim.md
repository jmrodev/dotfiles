# ⚡ NEOVIM / LAZYVIM CHEATSHEET

## Navegación & Búsqueda
- `<Space> + <Space>`: Buscar archivos en el proyecto (Find Files).
- `<Space> + /`: Búsqueda de texto en todo el proyecto (Live Grep).
- `<Space> + e`: Abrir / Cerrar explorador de archivos (Neo-tree).
- `<Space> + fb`: Buscar entre buffers abiertos.
- `gd`: Ir a la definición del símbolo bajo el cursor.
- `gr`: Ver todas las referencias del símbolo.
- `K`: Mostrar documentación hover / tipo de datos.

## Ventanas & Buffers
- `<Space> + w + s`: Dividir ventana horizontalmente.
- `<Space> + w + v`: Dividir ventana verticalmente.
- `<Space> + w + d`: Cerrar la ventana actual.
- `[b` / `]b`: Ir al buffer anterior / siguiente.
- `<Space> + bd`: Cerrar el buffer actual.

## Edición & LSP
- `<Space> + ca`: Code actions del LSP (quickfix, imports, etc.).
- `<Space> + cr`: Renombrar símbolo en todo el proyecto.
- `<Space> + cf`: Formatear buffer actual con formateador configurado.
